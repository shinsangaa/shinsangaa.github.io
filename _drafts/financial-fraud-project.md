## 프로젝트 배경

금융 취약계층도 직관적으로 확인할 수 있는 이상거래 경고 알림을 구상했습니다.

## 모델링 접근

- 데이터 수집 및 전처리: **내가 직접 사용한 데이터와 컬럼을 채울 것**
- 모델: LightGBM 등의 분류 모델 평가
- 평가 지표: 재현율, 정밀도, 혼동행렬 등 사용한 실제 결과로 입력

## Streamlit 알림 구현

- 이상거래 예측 확률에 따라 정상·주의·위험 상태 구분
- 음성 경고와 화면 안내를 활용한 사용자 경험 개선
- 시연 기준과 실제 업무용 기준은 별도로 검증 필요

## 어려웠던 점과 개선 계획

- 실제 적용 시 오탐·미탐의 비용 비교
- 경고 임계값 근거와 검증 데이터 성능 분석
- 개인정보 보호 및 접근성 테스트
