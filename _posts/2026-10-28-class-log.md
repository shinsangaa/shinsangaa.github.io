#### [13장] 가상 소프트웨어 개발 조직: ChatDev 멀티 에이전트
MVP (Model-View-Process) : SW 아키텍처 디자인 (model은 data)  
MVP (Minimum Viable Product)  

<건설현장 안전관리 자동화 서비스 플랫폼 개발해보자>  
<개발방법>  
관리소장, 현장직원 일하는 sandbox(작업공간) 필요 -> Linux, Docker 설치해 sandbox 만들기  
안전지침(문서) -> RAG로 설계  
직원A, B가 안전모 착용 실시간 확인 필요 -> 실시간 데이터 - 그리고 그 데이터를 관리소장이 확인  
직원A가 안전모 미착용 시 작업하면 안됨 -> 조건분기. 관리소장이 stop하게 함  
직원A, B는 각각의 함수. add_node로 생성  
state 클래스 내부에 안전모 착용/미착용 값 넣기  
각 직원의 안전모 착용 여부는 condition으로 넣기  

그 과정이 순환루프로 돌아야 함
