#### [10장] LangChain 기초와 LCEL 선형 에이전트 파이프라인
에이전틱 루프 완성 : 의도분석 -> 도구 호출 명령 -> 로컬 실행 -> 결과 피드백 -> 자연어 답변  
위의 과정을 만들기 위한 하나의 틀. 프레임워크가 LangChain이다.  
LangChain을 편하게 만들 수 있도록 나누는 하나의 표현식이 LCELL

Function Calling, Tool Calling 사용 시 밑에서 호출하는 것이 불편해 LangChain이 나옴  
LangChain 만들 때 순서대로 만들기 불편해 LCELL 나옴

TOOL_MAP 기능을 하는 것이 @tool (파이썬 함수 래핑)

* 아래 단계 기억하기!  
하지만 실무 엔터프라이즈 서비스에서는:  
(1) 문서를 검색해서 프롬프트에 넣고(RAG),  
(2) 번역을 한 뒤,  
(3) 특정 JSON 포맷으로 파싱하고,  
(4) 에러가 나면 다른 모델로 재시도(Fallback)하는 등의 복잡한 다단계 흐름이 요구됩니다.

invoke 함수 - 한번에 보여줌  
stream 함수 - 텍스트 생성되는대로 출력
