    ```powershell
    get-ExecutionPolicy
    ```

    - `Set`: 권한부여

    - `CurrentUser`: 현재 사용자
    - `RemoteSigned`: 권한 내용

### 2. 환경 설정하고 GPT API 시작하기
#### (1) API
- API는 프로그램 단의 대화에 사용하기 위해 미리 정해 놓은 규칙이다.
- API 사용하는 모델은 API 키를 발급받아야 한다.
- 오픈AI에서 APi-key 발급받은 후 창을 닫으면 다시 볼 수 없다. (메모장에 저장하기)
- APi-key를 git등에 올려놓으면 과금될 가능성이 크기 때문에 잘 보관해놓아야 한다.
- APi-key를 python창에 입력하면 안된다.

#### (2) OpenAI API 키 사용 방법
- OpenAI API 키 발급, 결제 => OpenAI 모델들 사용 준비완료
- python에서 아래 작업 필요
    - `OpenAI()` Lib 설치
    - `OpenAI()` 객체 설치
    - `create(Model, 응답, 질문)`: OpenAI 명령어 사용해 질문
    - `respond.text`: 답변 출력됨

- VS code 터미널창에서 python Lib 설치
    - **(venv)** 확인 필수
    - 위 명령어부터 먼저 입력하면 오류 발생 시 다음 명령어 실행
    ```powershell
    pip install openai == 1.58.1
    pip3 install openai == 1.58.1
    python pip3 install openai == 1.58.1
    ```
    - [![]({{ '/assets/images/naver-import/9fc501780c44/img-004.png' | relative_url }})](#)
    - [![]({{ '/assets/images/naver-import/9fc501780c44/img-005.png' | relative_url }})](#)

- `get_basic.py` 파일 생성
    - 설치된 라이브러리로부터 OpenAI만 내 코드로 불러오기
    ```python
    from openai import OpenAI
    ```
    - `OpenAI` : API key를 이용하여 접속하기 위한 클래스 (접속, 요청 명령어들 들어 있음)
    - 사용방법
    ```python
    저장할 이름 = OpenAI(api_key="발급받은 api키")
    client = OpenAI(api_key = "발급받은 api키")
    response = client.chat.completions.create(
    model = "사용할 모델명",
    messages = [{"role" : "역할", "content" = "질문내용"} # 역할: system, user 크게 두가지
    ]
    )
    # 답변 출력
    print(response.choices[0].message.content)
    ```

    ```python
    # response 구현하는 또 다른 방법
    response = client.chat.completions.create(
    model = "gpt-4o",
    temperature = 0.9 # 0~2 사이 소수점 입력. 2에 가까울수록 창의적, 0에 가까울수록 정확
    messages = [
    {"role" : "system", "content" : "너는 유치원 학생이야. 유치원생처럼 답변해줘."},
    {"role" : "user", "content" : "참새"},
    {"role" : "assistant", "content" : "짹짹"}, # 예시를 넣어줌
    {"role" : "user", "content" : "오리"}
    ]
    )
    ```
    - (참고) 26년 6월 GPT-6 Astra 모델 출시 후 명령어 변경됨 (변경사항 메일 수시로 확인)
        - `client.responses.create()` => `client.chat.completions.create()`
        - `input` => `messages: {"role": "user", "content": "..."}`
        - `response.output_text` => `response.choices[0].message.content`
    
    - 코드 설명
        - `response = client.chat.completions.creat`
            - `chat`: 챗봇
            - `create`: 만들겠다
        - `messages = [{"role" : "역할", "content" = "질문내용"}`
            - role: system, user, assistant 입력 가능
                - `system`: GPT의 역할을 설정
                - `user`: 언어 모델과 대화를 나누는 사용자
                - `assistant`: 답변에 도움주기 위해 기본적인 content를 작성 
                - 예시. gpt-4o 모델이 글을 잘 쓴다 - {"role" : "system", "content" = "너는 글을 잘 쓰는 작가야"}
                - 예시. {"role" : "user", "content" = "질문내용입력"}
                - 질문내용은 26년 최신내용 입력할 수 없다. 학습된 정보만 질문 가능하다.
        - response 답변 출력
            - response 안에 많은 정보가 저장되어 있다
            - `response.choices[0]`: response의 첫번째 값만 취함
            - `response.choices[0].message.content`: 질문의 대답을 갖고 있음
        - api 오류
            - 401오류: api키 안 맞음
            - 409오류: api키는 맞으나 남은 금액 없음

#### (3) API 키 관리하기
- VS Code 터미널에서 python-dotenv 라이브러리 설치
    ```powershell
    pip install python-dotenv
    ```
    - [![]({{ '/assets/images/naver-import/9fc501780c44/img-006.png' | relative_url }})](#)

- 프로젝트 폴더에 .env 파일 생성
    - work_LLM 폴더에 New file 생성 (venv 안에 파일 생성하면 안 된다!)
    - `OPENAI_API_KEY=sk...`

- 기존 get_basic.py 코드 수정
    ```python
    from openai import OpenAI
    from dotenv import load_dotenv
    import os
    load_dotenv() # .env파일을 찾아달라는 함수
    api_key = os.getenv('OPENAI_API_KEY') # .env파일에 저장된 openai, gemini등 원하는 API값 불러옴
    client = OpenAI(api_key = api_key)
    ```
- Git 사용 시 프로젝트 폴더에 `.gitignore` 파일 생성
    ```text
    .env
    .venv
    env/
    venv/
    ENV/
    env.bak
    venv.bak
    ```
