## 두 방식의 차이

**프롬프트 엔지니어링**은 모델 자체의 가중치를 바꾸지 않고 입력 지시문, 예시, 맥락을 설계하는 방식입니다. **파인튜닝**은 준비한 학습 데이터로 모델 파라미터를 추가 학습하는 방식입니다.

| 구분 | 프롬프트 설계 | 파인튜닝 |
|---|---|---|
| 모델 가중치 변경 | 없음 | 있음 |
| 시작 비용 | 상대적으로 낮은 편 | 데이터 준비·학습 비용 필요 |
| 바뀌는 사실 반영 | 적절한 문서 검색과 결합 가능 | 재학습 없이 즉시 반영되지는 않음 |
| 적합한 상황 | 빠른 실험, 태스크 설명 개선 | 일관된 형식·행동을 추가 학습할 필요가 있을 때 |

## 실제 업무에서의 판단

먼저 프롬프트와 평가 데이터를 마련하고, 최신 문서 검색이 필요한 상황이라면 RAG를 검토합니다. 그다음에도 일관된 형식 출력 등이 어렵다면 파인튜닝 필요성을 평가할 수 있습니다.
