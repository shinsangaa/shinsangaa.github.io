## 2. 핵심 개념 정리
### 1. LLM은 무엇인가?
#### (1) 생성형 AI: 새로운 데이터를 생성하는 능력에 초점을 맞춘 AI
- 텍스트를 입력하면 음성 데이터로 변환, 사용자가 입력한 텍스트에 적절한 이미지를 생성
#### (2) 대규모 언어 모델(LLM): 방대한 양의 텍스트 데이터를 학습하여 인간의 언어를 이해하고 생성
- 챗GPT를 활용하는 GPT가 대표적인 모델
- 학습한 데이터의 일부를 지운 후, 그 안에 어떤 말이 들어갈지를 확률적으로 예측하고 실제 답과 비교하는 방식으로 학습
- 일반적으로 스스로 생각하거나, 인터넷 결과를 검색하여 답변을 생성하지 않는다.
- 적절하게 답변할 수 있는 이유는 이어질 내용이 무엇일지 확률적으로 판단하여 그럴듯한 문장을 만들어 낸다 => 환각 현상 발생 가능

### 2. LLM의 종류
#### GPT
- 글쓰기, 번역, 요약, 코딩에 탁월하다. 텍스트, 이미지, 비디오, 음성까지 활용 가능한 멀티모달 모델로 발전
#### Gemini
- 텍스트, 이미지, 오디오, 비디오를 모두 처리할 수 있는 모델로 발전. 한국어 처리 수준급.
#### LLaMA
- 메타에서 발표한 언어 모델로 오픈소스를 지향. 고성능 모델은 HW를 갖추어야 한다.
- 일반 PC용 소규모 모델은 로컬 환경에서 실행할 수 있어서 외부로 데이터를 전송할 필요가 없고, 비용이 들지 않는다. 한국어 처리 미숙.
#### claude
- 엔트로픽에서 개발
#### deepseek
- 중국에서 오픈 소스로 공개된 언어 모델
- 단순히 다음 단어를 생성하기 전에 추론과정을 거쳐 더 나은 답변을 만드는 추론형 모델 딥시크-R1을 공개

### 2. LLM을 공부해야 하는 이유
#### (1) LLM 프로그래밍 경험 필요한 이유
- 실제 업무는 기업이나 개인의 특수한 요구에 맞춰 추가 작업이 필요한 경우가 많다.
- 기밀 정보는 생성형AI에 자료를 업로드할 수 없다.
- => 챗봇이나 AI에이전트를 직접 개발하거나 외주 개발자를 통해 제작한다.

#### (2) LLM을 사용하는 것이 부적합한 경우
- 회사의 기밀자료를 LLM에서 사용하면 해당 정보가 서비스를 제공하는 서버로 전송된다.
- 오픈AI의 API를 지나치게 많이 사용할 경우 과도한 비용이 발생한다.
- => 로컬에서 사용 가능하도록 SLM(Small Language Model)을 고려한다.


### 3. LLM의 한계를 보완하는 기술
#### (1) 프롬프트 엔지니어링 (prompt engineering)
- 프롬프트 : 언어에게 업무 매뉴얼을 제공
- 질문 시 존댓말X, 정확히 지시 (토큰 사용량 최소화 필요)
- 답변도 간단하게 하도록 지시

#### (2) 파인 튜닝 (fine-tuning)
- 이미 학습된 언어 모델에 추가 데이터를 학습시키는 기법
- 전체 모델을 재학습시키는 것이 아니므로 특정 분야에 맞게 최적화 가능하다.
- LLM은 특정 분야의 전문 지식이나 특정 언어에 취약하다.
- "너는 의사가 돼야 해"
- HW가 고성능이어야 한다.

#### (3) RAG (Retrieval Augmented Generation)
- LLM은 학습을 완료한 시점 이후로 생성된 외부의 정보는 알지 못한다.
- 필요한 정보를 검색해서 답변할 때 활용하도록 돕는 기술
- 질문이 들어 왔을 때 데이터베이스에서 관련정보 찾고 그 내용을 토대로 답변
- CRM(Customer Relationship Management, 고객 관계 관리)에서 활용
- 실험 data는 외부유출되면 안됨 - RAG 형태로 data를 넣음

#### (4) function calling & tool call
- LLM이 외부 API나 직접 만든 함수를 호출하여 그 결과를 바탕으로 답변할 수 있게 하는 기술
- function calling : user의 질문에 대답하기 위해 AI와 DB가 왔다갔다 함
    - 주어진 함수의 매개변수 형식을 명확하게 정의하고, 그 구조에 맞춰 함수를 호출하여 결과를 사용
- tool call : function calling을 활용
    - 랭체인과 같은 LLM 기반 프레임워크에서 텍스트로 요청을 보내 외부함수나 도구로 실행시킨 후, 그 결과를 처리

#### (5) 랭체인 (LangChain)
- LLM을 활용하여 애플리케이션을 개발하는 프레임워크
- PDF 파일이나 웹 사이트 검색 결과를 모델이 활용하려면 PDF를 전처리하여 텍스트로 변환하거나 웹사이트의 텍스트를 가져오는 등의 기능을 개발 => 랭체인은 LLM과 이런 기능을 결합해서 사용하기 편리하게 한다.
- 답변 형식을 강제하여 불확실성을 줄여준다.
- 여러 개의 AI 모델이 있고, 모델을 쉽게 교체 가능
- (ex) 당 관리방법과 그 내용을 문서화 - data 수집 / 분석 / 요약 / 문서화 / 이미지 모델 => AI Service Model
Model 최신으로 변경 ; 랭그래프

#### (6) 랭그래프 (LangGraph)
- 여러 AI Agent를 결합해 멀티 에이전트로 구현
- agent role 규제 필요
