datetime.date

>>> import datetime
>>> day1 = datetime.date(2026, 10, 1)
>>> day2 = datetime.date(2026, 10, 4)
>>> diff = day2 - day1
>>> diff.days
3

>>> day = datetime.date(2026, 10, 4)
>>> day.weekday()
6
>>> day.isoweekday()
7

.weekday() 사용 시 : 0 월요일, 1 화요일, ... , 5 토요일, 6 일요일

.isoweekday() 사용 시 : 1 월요일, 2 화요일, ... , 6 토요일, 7 일요일

time 모듈

time.time() : 현재 시간을 실수 형태로 반환. 1970년 1월 1일 0시 0분 0초 기준으로 기잔 시간을 초 단위로 반환

>>> import time
>>> time.time()
1791097213.3348908

​

time.localtime : time.time()이 반환한 실수값을 연, 월, 일, 시, 분, 초, ... 형태로 바꾸어 주는 함수

time.localtime() => 현재시각 기준으로 출력됨

>>> time.localtime(time.time())
time.struct_time(tm_year=2026, tm_mon=10, tm_mday=4, tm_hour=16, tm_min=1, tm_sec=22, tm_wday=6, tm_yday=277, tm_isdst=0)

​

time.asctime : time.localtime이 반환한 튜플 값을 인수로 받아 날짜와 시간을 알아보기 쉬운 형태로 반환

time.asctime() => 현재시각 기준으로 출력됨

>>> time.asctime(time.localtime(time.time()))
'Sun Oct 4 16:03:01 2026'

​

time.ctime() : 위 코드와 같은 값을 출력하는데, 다른점은 항상 현재 시간만을 반환한다.

>>> time.ctime()
'Sun Oct 4 16:04:18 2026'

​

time.strftime : 시간에 관계된 것을 세밀하게 표현하는 여러 포맷 코드를 제공

time.strftime('%c') => 현재시각 기준으로 출력됨

>>> import time
>>> time.strftime('%x', time.localtime(time.time()))
'10/04/26'
>>> time.strftime('%c', time.localtime(time.time()))
'Sun Oct 4 16:05:59 2026'

time.sleep : 루프 안에서 많이 사용. 일정한 시간 간격을 두고 루프 실행 가능. 인수는 실수 형태 쓸 수 있다.

# sleep1.py
import time
for i in range(10):
print(i)
time.sleep(1)

random을 이용한 예제

리스트 요소 중 무작위로 하나를 선택하여 꺼낸 다음 그 값을 반환. 꺼낸 요소는 pop 메서드에 의해 사라진다

# random_pop.py
import random
def random_pop(data):
number = random.randint(0, len(data)-1)
return data.pop(number)
if __name__ == "__main__":
data = [1, 2, 3, 4, 5]
while data:
print(random_pop(data))
>> 실행 결과 <<
4
5
2
3
1

random 모듈의 choice 함수를 사용해 random_pop 함수를 더 직관적으로 만들어 보자.

def random_pop(data):
number = random.choice(data)
data.remove(number)
return number
