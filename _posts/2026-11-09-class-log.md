### Part1. 자율주행 빅데이터 인프라 혁신 (클라우드 네이티브 환경 구축)
PART 1 핵심 전문 용어 사전 (Terminology)
| 핵심 용어 | 영문 표기 | 직관적 비유 및 한 줄 정의 |
|---|---|---|
| **WSL2** | Windows Subsystem for Linux 2 | 윈도우 안에서 실제 리눅스 커널을 경량 가상 머신으로 구동하는 기술 |
| **Docker** | Container Virtualization | 소프트웨어를 실행에 필요한 라이브러리와 함께 독립된 컨테이너 상자로 격리·실행하는 기술 |
| **Docker Compose** | Multi-Container Orchestration | 여러 개의 컨테이너(하둡, 카프카, 하이브 등)를 YAML 파일 하나로 일괄 기동·관리하는 도구 |
| **Poetry** | Deterministic Python Packaging | 의존성 관리와 `poetry.lock` 파일을 통해 재현 가능한 Python 가상환경을 구성하는 도구 |
| **HDFS** | Hadoop Distributed File System | 대용량 파일을 여러 블록(일반적인 크기 128MB)으로 나누어 여러 서버에 분산 저장하는 파일시스템 |
| **NameNode** | HDFS Master Coordinator | HDFS의 디렉터리 구조와 파일 블록의 위치 정보를 관리하는 마스터 노드 |

#### Ch 01. 자율주행 AI 자동차와 빅데이터의 만남
```powershell
# 1. 윈도우 powershell -> 리눅스 WSL2 진입
PS C:\Users\PC> wsl

# 2. 초고속 리눅스 홈(~)으로 변경
pc@DESKTOP-NUVH6QH:/mnt/c/Users/PC$ cd ~

# 3. 실습 프로젝트 폴더로 이동
pc@DESKTOP-NUVH6QH:~$ cd ~/smartcar-pilot
```

Step 1. WSL2 설치 (윈도우 파워쉘 관리자 권한)
```powershell
PS C:\Users\PC> wsl --install -d Ubuntu-22.04
``` 

Step 2. 리눅스 홈으로 이동 및 필수 개발 도구 패키지 업데이트
```powershell
pc@DESKTOP-NUVH6QH:~$ cd ~

pc@DESKTOP-NUVH6QH:~$ sudo apt update && sudo apt upgrade -y
# && : 명령어 2개 이상 붙여 쓸 때 사용
# apt는 최신 패키지 목록을 가져와라
# sudo 관리자 권한을 이용해 apt에 저장된 최신 패키지 목록을 업데이트하라
# -y : yes 옵션 자동선택

pc@DESKTOP-NUVH6QH:~$ sudo apt install -y curl wget git build-essential libsasl2-dev libsasl2-modules
# curl wget : 외부로부터 api 통해 받아라 - Github 저장소에서 가져오기 위해
# build-essential : C나 C++ 컴파일 시 필요한 도구들
# libsasl2-dev libsasl2-modules : 네트워크 처리 부분
```

#### Ch 02. 가장 깔끔한 파이썬 프로젝트 도구: Poetry
Step 1. Poetry 설치 (WSL2 리눅스 홈 프롬프트)
```powershell
pc@DESKTOP-NUVH6QH:~$ curl -sSL https://install.python-poetry.org | python3 -
pc@DESKTOP-NUVH6QH:~$ export PATH="$HOME/.local/bin:$PATH"
pc@DESKTOP-NUVH6QH:~$ poetry --version
```

Step 2. 실습 프로젝트 폴더 생성 및 프롬프트 이동
```powershell
pc@DESKTOP-NUVH6QH:~$ mkdir -p ~/smartcar-pilot
# -p : 상위 폴더가 없으면 중간 폴더 자동생성하라

pc@DESKTOP-NUVH6QH:~$ cd ~/smartcar-pilot
```

Step 3. pyproject.toml 파일 생성
```powershell
# cat : 파일 없으면 생성하고, 있으면 수정하라 (EOF 만나지 전까지 내용을)
# [tool.poetry] 라는 tool을 만든다
cat << 'EOF' > pyproject.toml
[tool.poetry]
name = "smartcar-lakehouse"
version = "1.0.0"
description = "자율주행 AI 자동차 빅데이터 레이크하우스 실습 킷"
authors = ["DMDG 출판부 <dmdg@dmdg.live>"]
readme = "README.md"

[tool.poetry.dependencies]
python = ">=3.11,<4.0"
pyhive = "^0.7.0"
thrift = "^0.16.0"
thrift-sasl = "^0.4.3"
kafka-python = "^2.0.2"
pandas = "^2.2.0"
numpy = ">=2.0.0"
scikit-learn = "^1.4.0"
statsmodels = "^0.14.0"
seaborn = "^0.13.0"
matplotlib = "^3.8.0"

[build-system]
requires = ["poetry-core"]
build-backend = "poetry.core.masonry.api"
EOF
```

Step 4. 원클릭 패키지 설치
```powershell
pc@DESKTOP-NUVH6QH:~/smartcar-pilot$ poetry install
```

```powershell
pc@DESKTOP-NUVH6QH:~/smartcar-pilot$ code .
```
