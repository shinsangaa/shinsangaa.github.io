4. get_basic.py 파일 생성

# 설치된 라이브러리로부터 OpenAI만 내 코드로 불러오기
from openai import OpenAI
# OpenAI : API key를 이용하여 접속하기 위한 클래스
# OpenAI 내부에 접속하고 요청할 수 있는 명령어들이 들어 있기 때문에...
# 사용방법
# 저장할 이름 = OpenAI(api_key="발급받은 api키")
client = OpenAI(api_key = "발급받은 api키")
response = client.chat.completions.create(
model = "사용할 모델명",
messages = [{"role" : "역할", "content" = "질문내용"} # 역할: system, user 크게 두가지
]
)
# 답변 출력
print(response.choices[0].message.content)
# response 구현하는 또 다른 방법
'''

messages = [
{"role" : "system", "content" : "너는 유치원 학생이야. 유치원생처럼 답변해줘."},

(1) from openai import OpenAI

설치된 openai 라이브러리로부터 OpenAI만 내 코드로 불러오기

openai - Library명

OpenAI - 하나의 파이썬 파일 (OpenAI.py)

​

(2) api 오류

401오류 - api키 안 맞음

409오류 - api키는 맞으나 남은 금액 없음

​

(3) response = client.chat.completions.creat

chat - 챗봇

create - 만들겠다

​

(4) messages = [{"role" : "역할", "content" = "질문내용"}

role - system, user 입력 가능

Agent에 역할 부여 시 role에 system 입력, 질문 던지려면 user 입력

(ex1) gpt-4o 모델이 글을 잘 쓴다 - {"role" : "system", "content" = "너는 글을 잘 쓰는 작가야"}

(ex2) {"role" : "user", "content" = "질문내용입력"}

질문내용은 26년 최신내용 입력할 수 없다. 학습된 정보만 질문 가능하다.

​

(5) response 답변 출력

response 안에 많은 정보가 저장되어 있다

response.choices[0] - response의 첫번째 값만 취함

response.choices[0].message.content - 질문의 대답을 갖고 있음
