아래는 원하는 대로 동작하지 않은 코드이다.

# 신문 배달을 하는 프로그램 작성
# 아래의 arrears 리스트는 신문 구독료 미납세대. 해당 세대는 신문 배달하지 않아야 한다.
apart = [[101, 102, 103, 104],
[201, 202, 203, 204],
[301, 302, 303, 304],
[401, 402, 403, 404]]
arrears = [101, 203, 301, 404]
def apart_array(apart) :
array = []
for i in apart :
array.extend(i)
return array
array = apart_array(apart) # [101, 102, 103, 104, 201, 202, 203, 204, 301, 302, 303, 304, 401, 402, 403, 404]
delivery = []
for i in array :
for j in arrears :
if i != j :
delivery.append(i)
print(f'신문을 배달해야 하는 세대 : {delivery}')

실행 결과
신문을 배달해야 하는 세대 : [101, 101, 101, 102, 102, 102, 102, 103, 103, 103, 103, 104, 104, 104, 104, 201, 201, 201, 201, 202, 202, 202, 202, 203, 203, 203, 204, 204, 204, 204, 301, 301, 301, 302, 302, 302, 302, 303, 303, 303, 303, 304, 304, 304, 304, 401, 401, 401, 401, 402, 402, 402, 402, 403, 403, 403, 403, 404, 404, 404]

if문에서 미납세대와 동호수가 같지 않은 경우에만 delivery 리스트에 append 하도록 작성했으나

실행 결과 중복값이 여러 번 들어가고, 미납세대도 포함되어 있다.

​

이유

내가 작성한 코드는 array의 각 동호수(i) 하나를 arrears의 동호수 4개(j)와 각각 1:1로 비교하여 그때마다 리스트에 추가하는 코드이다.

i = 101 일 때, j = 101일 때는 거짓이라서 delivery 리스트에 추가되지 않는다.

그러나 i = 101 이고, j = 203, 301, 404 가 될 때에는 조건 (101 != 203) 이 참이 된다.

그러므로 i인 101이 3번이나 delivery 리스트에 들어가게 된다.

​

해결

이중 for문 사용하지 않고 not in 연산자 사용

# for문 부분 수정
delivery = []
for i in array:
if i not in arrears:
delivery.append(i)
# 리스트 컴프리헨션 이용해 간단하게 작성 가능 (위의 for문과 같은 동작)
delivery = [i for i in array if i not in arrears]
