all(x) : 반복 가능한 데이터 x를 입력으로 받아 x의 요소가 모두 참이면 True, 거짓이 하나라도 있으면 False 반환

False
>>> all([]) # all의 입력 인수가 빈값이 경우 True 반환

eval(expression) : 문자열로 구성된 표현식을 입력으로 받아 해당 문자열을 실행한 결과값 반환

eval은 입력 문자열을 실제로 실행하므로, 신뢰할 수 없는 외부 입력에는 사용하면 안됨

>>> eval('1+2')

>>> eval("'hi'+'a'")
'hia'
>>> eval('divmod(4, 3)')
(1, 1)

isinstance(object, class) : 첫 번째 인수로 객체, 두 번째 인수로 클래스를 받음

입력받은 객체가 해당 클래스의 인스턴스인지 판단하여 참이면 True, 거짓이면 False 반환

>>> class Person: pass
...
>>> a = Person()
>>> isinstance(a, Person)
True
>>> b = 3
>>> isinstance(b, Person)
False

a가 Person 클래스로 만든 인스턴스임을 확인. b는 Person 클래스로 만든 인스턴스가 아니므로 False 반환

map(f, iterable) : 함수(f)와 반복 가능한 데이터를 입력으로 받음.

입력받은 데이터의 각 요소에 함수 f를 적용한 결과를 반환하는 함수

# two_times.py
def two_times(numberList):
result = []
for number in numberList:
result.append(number \* 2)
return result
result = two_times([1, 2, 3, 4])
print(result)

map 함수를 사용해 위와 같은 기능 구현 가능

>>> def two_times(x):
... return x\*2
...
>>> list(map(two_times, [1, 2, 3, 4]))
[2, 4, 6, 8]

lambda 사용해 더 간단히 만들 수 있다.

>>> list(map(lambda a:a\*2, [1, 2, 3, 4]))
[2, 4, 6, 8]
